# Cow Hawk site

Public support and privacy pages for the Cow Hawk iOS app.

The app source stays in a separate private repo: [Fishnet-hue/CowHawk](https://github.com/Fishnet-hue/CowHawk).

**Sean:** enable GitHub Pages — Settings → Pages → Deploy from branch `main` / root (same as other Fishnet Hue sites).

After Pages is on:

- Home: https://fishnet-hue.github.io/cow-hawk-site/
- Support: https://fishnet-hue.github.io/cow-hawk-site/support.html
- Privacy: https://fishnet-hue.github.io/cow-hawk-site/privacy.html
